01 · Über mich

Wer ich bin

Ich bin Justin Linh und wohne in der Schweiz. Mich fasziniert, wie aus ein paar Zeilen Code ein Programm wird, das wirklich etwas tut. Angefangen hat es im Unterricht mit C#. Seither probiere ich gerne selbst Dinge aus, lese mich in neue Themen ein und versuche, meinen Code von Mal zu Mal sauberer zu schreiben.

Neben der Programmierung arbeite ich mit SQL-Datenbanken, baue kleine Webseiten mit HTML, CSS und JavaScript und automatisiere Abläufe mit PowerShell. Meinen Code verwalte ich mit Git und GitHub.

Mein Ziel ist eine Lehre als Informatiker. Vorher möchte ich in einem Praktikum herausfinden, wie der Alltag in einem Entwicklungsteam aussieht, und dort so viel wie möglich lernen.

  • Sauber arbeiten

    Verständliche Namen, kurze Methoden und Kommentare dort, wo sie helfen.

  • Strukturiert vorgehen

    Ich dokumentiere Projekte nach IPERKA: informieren, planen, entscheiden, realisieren, kontrollieren, auswerten.

  • Dranbleiben

    Wenn etwas nicht funktioniert, suche ich so lange, bis ich verstehe, warum.
